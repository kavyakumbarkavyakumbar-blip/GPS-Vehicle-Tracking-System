
# GPS Vehicle Tracking System

Overview
The GPS Vehicle Tracking System is an embedded system project developed using Embedded C and 8051 Microcontroller. This project receives real-time location data from a GPS module through UART communication and displays latitude and longitude coordinates for vehicle tracking applications.

---

## Objective

To design and implement a GPS-based tracking system for monitoring vehicle location using UART communication and Embedded C programming.

---

## Features

* Real-time GPS location tracking
* UART serial communication
* Latitude and longitude monitoring
* Serial monitor debugging
* Embedded C implementation

---

## Technologies Used

---

## Working Principle

The GPS module continuously transmits NMEA data through UART communication. The microcontroller receives the GPS data and sends it to the serial monitor for displaying real-time location information such as latitude and longitude.
